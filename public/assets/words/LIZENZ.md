# Wort-Bilder

Alle Bilder in diesem Ordner stammen von **OpenMoji** – the open-source emoji and icon project
(https://openmoji.org), Version 15.1.0, unverändert.

Lizenz: **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/)

Die Dateien sind nach der Wort-ID benannt (z. B. `hund.svg`). Geladen werden sie einmalig mit
`npm run words` (siehe `scripts/words/openmoji.ts`); zur Laufzeit gibt es keine Netzwerkanfragen.
